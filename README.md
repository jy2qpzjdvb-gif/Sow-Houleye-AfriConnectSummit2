# AfriConnect Summit

## Présentation

AfriConnect Summit est un site web moderne présentant un sommet africain dédié aux technologies, à l'innovation et à l'entrepreneuriat.

- Accueil moderne

- Présentation des intervenants

- Mode sombre

- Menu hamburger
